2. RAIZ DO BUG (ANÁLISE PROFUNDA)
================================================================================

MediaRecorder.start(timeslice) funciona assim:
  ├─ Se mimeType é SUPORTADO:
  │  ├─ Começa a gravar
  │  ├─ a cada timeslice ms, dispara ondataavailable
  │  └─ chunks são acumulados
  │
  └─ Se mimeType NÃO é suportado:
     ├─ Browser SILENCIOSAMENTE rejeita
     ├─ Ou começa a gravar mas com codec diferente
     ├─ ondataavailable pode não disparar (browser específico)
     └─ Ou dispara com dados vazios

PROBLEMA EM ALGUMAS PLATAFORMAS:
  - Chrome: Suporta audio/webm ✓
  - Firefox: Pode ter problemas com audio/webm ⚠️
  - Safari: NÃO suporta audio/webm ❌ (usa audio/mp4)
  - Edge: Suporta audio/webm ✓

PORQUE PARA NUM BROWSER ESPECÍFICO:
  User estava a usar Safari ou Firefox que não suportam audio/webm!

================================================================================
3. SOLUÇÃO IMPLEMENTADA
================================================================================

ANTES: Código rígido
```typescript
const mediaRecorder = new MediaRecorder(stream, { mimeType: 'audio/webm' });
```

DEPOIS: Fallback inteligente com MediaRecorder.isTypeSupported()
```typescript
let mediaRecorder: MediaRecorder;
const supportedMimeTypes = ['audio/webm', 'audio/mp4', 'audio/ogg', ''];
let selectedMimeType = '';

for (const mimeType of supportedMimeTypes) {
  try {
    if (mimeType && !MediaRecorder.isTypeSupported(mimeType)) {
      console.log('[useAudioTranscription] mimeType not supported:', mimeType);
      continue;
    }
    const options = mimeType ? { mimeType } : {};
    mediaRecorder = new MediaRecorder(stream, options);
    selectedMimeType = mimeType || '(default)';
    console.log('[useAudioTranscription] MediaRecorder created successfully with:', selectedMimeType);
    break;
  } catch (e) {
    console.log('[useAudioTranscription] Failed to create with:', mimeType, e);
    continue;
  }
}

if (!mediaRecorder) {
  throw new Error('Failed to create MediaRecorder with any supported mime type');
}
```

LÓGICA:
1. Tenta audio/webm (melhor)
2. Se falhar, tenta audio/mp4
3. Se falhar, tenta audio/ogg
4. Se falhar, tenta default (browser escolhe)
5. Se tudo falhar, lança erro

IMPACTO:
✓ Funciona em TODOS os browsers (Chrome, Firefox, Safari)
✓ Escolhe o melhor codec disponível
✓ Logging mostra qual foi escolhido
✓ Fallback automático
