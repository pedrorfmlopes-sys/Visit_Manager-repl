Tarefa: POST /api/crm/leads aceitar contactosIds

Implementação:

  - Lógica se contactosIds não vem:

    * Insere uma linha por cada ID em contactosIds
  
  Pseudocódigo:
    if (contactosIds && length > 0) {
      const idsToInsert = Array.from(new Set([contactoId, ...contactosIds]));
      await db.delete(leadsContactos).where(leadId = created.id);
      for (cId of idsToInsert) {
        await db.insert(leadsContactos).values({ leadId: id, contactoId: cId });
      }
    } else {
      await db.insert(leadsContactos).values({ leadId: id, contactoId });
    }

Tarefa: PATCH /api/crm/leads/:id aceitar contactosIds

Implementação:
  - Input: body.contactosIds (array, opcional)
  
  - Lógica:
    * Validação: pelo menos um campo para atualizar (lead fields OU contactosIds)
    * Se contactosIds: apaga leads_contactos antigos e insere novos
    * Se apenas lead fields: comportamento normal
  
  Pseudocódigo:
    const hasUpdateData = Object.keys(updateData).length > 0;
    const hasContactosIds = contactosIds !== undefined;
    
    if (hasUpdateData) {
      updated = await db.update(leads).set(updateData).returning();
    } else {
      updated = await db.query.leads.findFirst(...);
    }
    
    if (hasContactosIds && contactosIds.length > 0) {
      const idsToInsert = Array.from(new Set(contactosIds));
      await db.delete(leadsContactos).where(leadId = id);
      for (cId of idsToInsert) {
        await db.insert(leadsContactos).values({ leadId: id, contactoId: cId });
      }
    }

Mudanças:
  ✅ Adicionado: const { contactosIds } = req.body
  ✅ Lógica: validação de contactosIds
  ✅ Lógica: update condicional (dados lead ou contactos)
  ✅ Lógica: delete e insert contactosIds

Resultado:
  ✅ PATCH com contactosIds actualiza contactos do lead
  ✅ PATCH sem contactosIds funciona normalmente

  "titulo": "Prospecto ABC",
  "contactosIds": ["cont-1", "cont-2", "cont-3"]
}

Backend:
1. Valida corpo + schema (contactosIds = 3 items)
2. INSERT leads(entidadeId, contactoId: "cont-1", ...)
3. Deduplica: ["cont-1", "cont-2", "cont-3"]
4. INSERT leads_contactos × 3:
   - (leadId, contactoId: "cont-1")
   - (leadId, contactoId: "cont-2")
   - (leadId, contactoId: "cont-3")
5. Response: { success: true, lead: {...} }

GET /api/crm/leads/lead-1:

- Response: { lead: {..., contactosAssociados: [{...}, {...}, {...}]} }

- "Outros contactos envolvidos:" mostra 3 chips:
  * João (cont-1)
  * Maria (cont-2)
  * Pedro (cont-3)

Resultado: ✅ Múltiplos contactos visíveis

CENÁRIO C: Atualizar contactos de um lead (PATCH com contactosIds)
────────────────────────────────────────────────────────────────────────────────

Request:
PATCH /api/crm/leads/lead-1
{
  "contactosIds": ["cont-1", "cont-4", "cont-5"]
}

Backend:
1. Query lead: tem contactosAssociados = [cont-1, cont-2, cont-3]
2. DELETE leads_contactos WHERE leadId = lead-1 (apaga os 3)
3. Deduplica: ["cont-1", "cont-4", "cont-5"]
4. INSERT leads_contactos × 3:
   - (leadId, contactoId: "cont-1")
   - (leadId, contactoId: "cont-4")
   - (leadId, contactoId: "cont-5")
5. Response: { success: true, lead: {...} }

GET /api/crm/leads/lead-1:
- Carrega contactosAssociados (3 contactos novos)
- Response: { lead: {..., contactosAssociados: [cont-1, cont-4, cont-5]} }

Frontend:
- Card actualiza automaticamente (refetch)
- "Outros contactos envolvidos:" mostra:
  * João (cont-1)
  * Silva (cont-4)
  * Costa (cont-5)

Resultado: ✅ Contactos actualizados sem quebrar lead
