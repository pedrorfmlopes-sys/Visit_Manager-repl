COMPORTAMENTO APÓS INTEGRAÇÃO
================================================================================

1. Criar novo lead:
   - User clica em "Novo lead"
   - Form renderiza entidade/contacto com SearchSelect
   - User digita em Entidade → debounce 300ms → dropdown com resultados

2. Selecionar entidade:
   - User clica em entidade
   - entidadeId atualizado
   - contactoId resetado (lógica: new entidade = reset contacto)
   - ContactoSearchSelect ativa automaticamente (disabled=false)

3. Buscar contacto:
   - ContactoSearchSelect já tem entidadeId
   - Endpoint /api/crm/contactos/search?q=...&entidadeId=... chamado
   - Dropdown mostra SÓ contactos dessa entidade

4. Submeter formulário:
   - Validação: se(!entidadeId && !contactoId) → erro
   - Payload enviado com entidadeId/contactoId corretos
   - NavigateReturnTo ou /admin/leads ou /visitas/{id}

5. Estados de loading:
   - Ícone de carregamento durante debounce
   - Dropdown "A carregar..." se fetch ainda pendente
   - "Sem resultados" se nenhuma entidade/contacto encontrado
