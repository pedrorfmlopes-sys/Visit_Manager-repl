2. FLUXO DE USO (NOVO)
================================================================================

Cenário: Criar nova visita com anotações ditadas

1. User abre /visitas/nova
2. Preenche entidade, contacto, data (normalmente)
3. Encontra seção "Ditar Anotações" (nova!)
4. Clica "Gravar"
   → Browser pede permissão do micro
   → Botão fica vermelho "Parar (0s)"
   → Contador avança
5. User fala (5-30 segundos)
6. Clica "Parar"
   → Gravação para
   → Toast: "Áudio gravado" (interno)
   → Botão "Transcrever áudio" fica ativo
7. Clica "Transcrever áudio"
   → Botão muda para "A transcrever..."
   → Envia para /api/visitas/ai/transcribe
   → OpenAI Whisper transcreve
   → Callback onTranscriptionComplete dispara
   → Texto adicionado ao campo "Notas da Visita" com prefixo "[Áudio transcrito]"
   → Toast: "Áudio transcrito - Texto adicionado às notas da visita."
8. User vê texto no campo de notas
   → Pode editar, formatar, adicionar mais texto
9. Clica "Guardar Visita"
   → POST /api/visitas com notas + áudio transcrito

IMPORTANTE: Isto tudo acontece ANTES de a visita ser criada no backend!
- Não depende de visitaId
- O endpoint de transcrição é genérico
- O texto fica no campo local (form state) até guardar

4. TECNICAMENTE: COMO FUNCIONA
================================================================================

Hook Integration:
```typescript
const audio = useAudioTranscription({
  transcriptionEndpoint: '/api/visitas/ai/transcribe',
  onTranscriptionComplete: (text) => {
    // Callback ao transcrever com sucesso
    const currentNotas = form.getValues("notas") || "";
    const updatedNotas = currentNotas 
      ? currentNotas + "\n\n[Áudio transcrito]\n" + text
      : text;
    form.setValue("notas", updatedNotas);
    toast({ title: "Áudio transcrito", ... });
  },
  onError: (error) => {
    console.error("[VisitaForm] Audio transcription error:", error);
  }
});
```

UI Components:
- Button "Gravar/Parar": Alterna entre startRecording e stopRecording
- Button "Transcrever áudio": Chama audio.transcribe()
- Mensagens condicionais: mostra feedback baseado em states

Estados Usados:
- audio.isRecording: Botão fica vermelho
- audio.isTranscribing: Botão fica disabled + texto muda
- audio.hasAudio: "Transcrever áudio" só ativo se true
- audio.recordingTime: Contador de segundos
- audio.supportsRecording: Aviso se browser não suporta
