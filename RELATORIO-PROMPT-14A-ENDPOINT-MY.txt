  4. Extrai user do req.user

  6. Extrai userId de user.claims.sub

  8. Query database com filtro:
     - SELECT * FROM odooContactRequests

  9. Se sucesso: responde { success: true, data: pedidos[] }
  10. Se erro: responde { success: false, message: "Erro..." }
