FLUXO DE INTERACAO
================================================================================

1. User abre /admin/leads (sem filtros)
   - URL: /admin/leads
   - Filtros: vazios (defaults)
   - Query: GET /api/crm/leads?orderBy=createdAt&orderDir=desc
   - Display: últimos 100 leads

2. User digita "Acme" no search
   - URL: /admin/leads?q=acme
   - State: q = "acme"
   - Query: GET /api/crm/leads?q=acme&orderBy=createdAt&orderDir=desc
   - Auto-refetch leads com filtro

3. User seleciona estado "Novo"
   - URL: /admin/leads?q=acme&estado=novo
   - State: q = "acme", estado = "novo"
   - Query: GET /api/crm/leads?q=acme&estado=novo&...
   - Auto-refetch com 2 filtros

4. User clica "Limpar filtros"
   - URL: /admin/leads (sem query params)
   - State: todos revert para defaults
   - Query: GET /api/crm/leads?orderBy=createdAt&orderDir=desc
   - Back ao estado inicial

5. User seleciona "Título A-Z"
   - URL: /admin/leads?orderBy=titulo&orderDir=asc
   - Query: GET /api/crm/leads?orderBy=titulo&orderDir=asc
   - Leads mostrados ordenados por título A-Z

================================================================================
DETALHES TECNICOS
================================================================================

Query params na URL:
  - Tipo: URLSearchParams (formato URL padrão)
  - Encoding: automático (URL-safe)
  - Exemplo: ?q=acme&estado=novo&orderBy=titulo&orderDir=asc

Query Key para react-query:
  - Key: ["/api/crm/leads", { q, estado, entidadeId, contactoId, hasOdoo, orderBy, orderDir }]
  - Rationale: refetch sempre que um param muda (automático)
  - Caching: React Query cache hit quando URL = Query Key

API call:
  - URL: GET /api/crm/leads?q=...&estado=...&orderBy=...
  - Backend: Já implementado (FASE-LEADS-FILTROS-01)
  - Response: { leads: [...] } (unchanged)

Reset function:
  - navigate("") limpa toda a search string
  - React Query refetches com params vazios
  - useLocation updates automaticamente
