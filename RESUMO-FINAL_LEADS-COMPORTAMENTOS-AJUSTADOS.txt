PARTE 2B: VOLTAR DO DETALHE AO LEAD

Ficheiros: EntidadeDetail.tsx, ContactoDetail.tsx, VisitaDetail.tsx (3 edits)

Cada seta de voltar agora implementa:

```ts
onClick={() => {
  const searchParams = new URLSearchParams(window.location.search);
  const returnTo = searchParams.get("returnTo");
  if (returnTo) {
    setLocation(decodeURIComponent(returnTo));
  } else {
    setLocation("/entidades"); // ou /contactos, /visitas conforme
  }
}}
```

LOGICA:
  ✓ Se returnTo existe → volta para lead (/admin/leads/:id)
  ✓ Se returnTo não existe → volta para lista (comportamento padrão)

RESULTADO:
  User em /admin/leads/:id
    → Clica "Entidade" → /entidades/:id?returnTo=/admin/leads/:id
      → Clica seta voltar → /admin/leads/:id ✓
