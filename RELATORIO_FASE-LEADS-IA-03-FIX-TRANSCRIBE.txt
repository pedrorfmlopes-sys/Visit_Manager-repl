================================================================================
1. PROBLEMA IDENTIFICADO
================================================================================

BUG Reportado:
- Botao "Dictar" grava audio com sucesso
- Ao terminar gravacao, aparece toast: "Falha na transcrição"
- Erro na resposta JSON: "require is not defined"

Causa Real:
- Ficheiro: server/routes/crmLeads.ts, linhas 580-581
- Problema: Uso de `require()` em ambiente ESM
  ```typescript
  const fs = require("fs");    // ❌ ESM NAO TEM require()
  const path = require("path"); // ❌ ESM NAO TEM require()
  ```
- Contexto: O ficheiro importa com syntax ESM no topo:
  ```typescript
  import express from "express";
  import { db } from "../db";
  ```
- Em ESM, `require` é undefined porque não existe por defeito
- Quando o handler tenta usar `require()`, lança: "require is not defined"
- Erro é capturado no try/catch e devolvido na resposta JSON ao cliente

================================================================================
2. SOLUCAO IMPLEMENTADA
================================================================================

Passo 1: Adicionar Imports ESM No Topo Do Ficheiro
- Ficheiro: server/routes/crmLeads.ts, linhas 1-11
- ANTES:
  ```typescript
  import express from "express";
  import { and, eq } from "drizzle-orm";
  import { db } from "../db";
  ...
  ```
- DEPOIS:
  ```typescript
  import express from "express";
  import { and, eq } from "drizzle-orm";
  import fs from "fs";           // ✅ NOVO
  import path from "path";       // ✅ NOVO
  import { db } from "../db";
  ...
  ```
- Resultado: fs e path agora disponíveis em todo o modulo

Passo 2: Remover `require()` Do Handler
- Ficheiro: server/routes/crmLeads.ts, POST /ai/transcribe (linhas 574-629)
- ANTES (Linhas 580-581):
  ```typescript
  const fs = require("fs");
  const path = require("path");
  ```
- DEPOIS:
  ✅ REMOVIDAS (agora fs e path vem dos imports)
  ✅ Usar diretamente: fs.promises.writeFile(), path.join()

Passo 3: Melhorar Error Handling
- ANTES:
  ```typescript
  message: "Failed to transcribe audio: " + (error?.message || "Unknown error")
  ```
  - Devolvia erro técnico: "require is not defined" ao cliente
  - Confuso e expõe internals

- DEPOIS:
  ```typescript
  // Log server-side (técnico)
  console.error("[CRM Leads AI] Transcription error details:", {
    error: transcribeError?.message || String(transcribeError),
    stack: transcribeError?.stack,
    tmpFile,
  });
  
  // Return friendly message to client (português, amigável)
  message: "Falha ao transcrever áudio. Por favor, tenta novamente."
  ```
  
  Beneficios:
  - Admin vê erro completo nos logs do servidor
  - User vê mensagem amigável em português
  - Nenhum technical detail exposto ao cliente
  - Stack trace aparece só no console backend
