4. QUERY PARAMS (URL)
================================================================================

ESTRUTURA:
  /admin/leads/new?visitaId=<visitaId>&returnTo=<URL>

EXEMPLO:
  /admin/leads/new?visitaId=451a15f4-4381-4c2a-b086-b5c9d1441468&returnTo=/admin/visitas/451a15f4-4381-4c2a-b086-b5c9d1441468

PARAMETROS:
- visitaId: UUID da visita (linkado ao lead)
- returnTo: URL para voltar depois de criar (ex: visita detail page)

LEITURA EM CODIGO:
  const search = useSearch();
  const searchParams = new URLSearchParams(search);
  const visitaId = searchParams.get("visitaId");
  const returnTo = searchParams.get("returnTo");

USO:
- visitaId: Passado para LeadDetailForm, usado em POST body
- returnTo: Usado na navegação pós-criação
