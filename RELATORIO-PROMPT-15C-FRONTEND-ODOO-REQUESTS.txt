2.3 - QUERY: GET /api/odoo/contact-requests/my

  const { data: myOdooRequests = [], isLoading, isError } = useQuery<MyOdooRequest[]>({
    queryKey: ["/api/odoo/contact-requests/my"],
    queryFn: async () => {
      const res = await fetch("/api/odoo/contact-requests/my");
      if (!res.ok) {
        throw new Error("Failed to fetch my Odoo requests");
      }
      const json = await res.json();
      if (!json.success) {
        throw new Error(json.message || "Erro ao carregar os teus pedidos.");
      }
      return json.data as MyOdooRequest[];
    },
  });

2.4 - USEEFFECT: MARCAR COMO VISTOS

  useEffect(() => {
    if (isLoading || myOdooRequests.length === 0) return;

    const hasUnseenDone = myOdooRequests.some(
      (r) => r.estado === "concluido" && !r.userSeenAt
    );
    if (!hasUnseenDone) return;

    (async () => {
      try {
        const res = await fetch(
          "/api/odoo/contact-requests/my/mark-seen",
          { method: "PATCH" }
        );
        const json = await res.json();
        if (json.success) {
          queryClient.invalidateQueries({
            queryKey: ["/api/odoo/contact-requests/my"],
          });
        }
      } catch (e) {
        console.error("Erro ao marcar pedidos como vistos", e);
      }
    })();
  }, [isLoading, myOdooRequests, queryClient]);

LÓGICA:

  1. Guard: Se loading ou sem dados → sair
  2. Check: Existe algum concluído não visto?
     - hasUnseenDone = true: tem pendentes
     - hasUnseenDone = false: todos vistos, não fazer nada
  3. Se hasUnseenDone: chamar PATCH /mark-seen
  4. Se sucesso: invalidar cache
     - Força recarregamento automático
     - Dashboard card atualiza
     - myDone recalculado
  5. Se erro: log ao console (não quebra UI)

DEPENDENCIES:
  - [isLoading, myOdooRequests, queryClient]
  - Triggered quando: página abre, dados carregam, query refresha
  - Uma vez por sessão: handleUnseen detecta se já fez (hasUnseenDone)

FLUXO EXEMPLO:
  1. User abre /me/odoo-requests
  2. Query carrega: [req1(unseen), req2(unseen), req3(seen)]
  3. useEffect roda → hasUnseenDone = true
  4. Chama PATCH /mark-seen
  5. Backend: UPDATE userSeenAt = now() para req1, req2
  6. invalidateQueries: reload data
  7. Query recarrega: [req1(seen), req2(seen), req3(seen)]
  8. useEffect roda novamente → hasUnseenDone = false
  9. Sai cedo, não chama PATCH novamente
  10. Dashboard myDone recalculado = 0
