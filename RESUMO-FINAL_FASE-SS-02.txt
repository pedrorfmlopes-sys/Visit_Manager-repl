================================================================================
COMPORTAMENTO DO COMPONENTE
================================================================================

1. Entrada de texto:
   - Debounce 300ms antes de chamar fetchOptions
   - Mínimo 1 caractere por padrão (configurável)
   - Input mostra label selecionado ou texto de busca

2. Dropdown:
   - Abre automaticamente quando há resultados
   - Cada opção mostra label + extraInfo (se existir) em texto menor
   - Botão "x" para limpar seleção
   - Ícone de carregamento durante busca

3. Estados:
   - "A carregar..." enquanto busca
   - "Sem resultados" se não encontrar nada
   - Click outside fecha dropdown
   - Ícone ChevronDown quando não está selecionado

4. Limpeza de seleção:
   - Botão "x" aparece apenas quando algo está selecionado
   - Click limpa value, label, input
   - onChange(null) chamado ao limpar

EXEMPLO DE USO SIMPLES
================================================================================

Uso básico com endpoint:

```typescript
import { SearchSelect } from "@/components/SearchSelect";

export function MyForm() {
  const [selectedId, setSelectedId] = useState<string | null>(null);

  const fetchEntidades = async (q: string) => {
    const res = await fetch(`/api/crm/entidades/search?q=${q}`);
    return res.json();
  };

  return (
    <SearchSelect
      value={selectedId}
      onChange={setSelectedId}
      fetchOptions={fetchEntidades}
      label="Selecionar Entidade"
      placeholder="Pesquisar entidade..."
    />
  );
}
```

Uso com contactos (com filtro entidade):

```typescript
const fetchContactosByEntidade = async (q: string) => {
  const res = await fetch(
    `/api/crm/contactos/search?q=${q}&entidadeId=${entidadeId}`
  );
  return res.json();
};

<SearchSelect
  value={selectedContacto}
  onChange={setSelectedContacto}
  fetchOptions={fetchContactosByEntidade}
  label="Contacto"
  disabled={!entidadeId} // Ativa apenas se entidade selecionada
/>
```
