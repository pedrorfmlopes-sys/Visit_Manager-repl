1) Refatorar buildEntidadeAccessWhere para função de módulo (sem this)

Ficheiro a editar:
server/storage.ts (onde o agent criou buildEntidadeAccessWhere e onde estão getEntidades / getEntidade).

Tarefas:

Se buildEntidadeAccessWhere estiver dentro de uma classe (ex.: private buildEntidadeAccessWhere(...) {}):

Corta todo o método da classe.

Cola-o fora da classe, no topo do ficheiro, como função normal:

import { and, or, eq } from "drizzle-orm";
import { entidades } from "../shared/schema"; // já deve existir

function buildEntidadeAccessWhere(
  empresaId: string,
  userId: string,
  userRole: "admin" | "agent"
) {
  if (userRole === "admin") {
    // Admin vê todas as entidades da empresa
    return eq(entidades.empresaId, empresaId);
  }

  // Agent: só entidades da empresa em que é criador ou assigned
  return and(
    eq(entidades.empresaId, empresaId),
    or(
      eq(entidades.createdByUserId, userId),
      eq(entidades.assignedUserId, userId)
    )
  );
}


Garante que entidades.createdByUserId e entidades.assignedUserId existem com esses nomes; se na schema forem outros, ajusta aqui.

Atualizar getEntidades para usar a função solta (sem this):

Procura getEntidades / listEntidades de Entidades e troca:
