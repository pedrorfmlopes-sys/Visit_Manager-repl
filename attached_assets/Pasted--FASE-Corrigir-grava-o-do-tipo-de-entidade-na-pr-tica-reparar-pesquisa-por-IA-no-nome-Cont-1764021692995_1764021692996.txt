2. Corrigir o fluxo de EDIÇÃO no EntidadeForm (se não estiver a sincronizar)

Em muitos casos, o problema não é a API, é o form em modo edição:

O useForm inicializa com defaultValues,

Quando a existingEntidade chega pelo React Query, se não fizeres reset(...), os valores do form não são atualizados,

Então o que tu vês/alteras pode não ser o que está realmente na BD.

No EntidadeForm.tsx:

Confirma se tens lógica do género:

const form = useForm({ defaultValues: { ... } });
const { data: existingEntidade } = useQuery(...);

useEffect(() => {
  if (existingEntidade) {
    form.reset({
      // todos os campos, incluindo:
      entidadeTipoId: existingEntidade.entidadeTipoId ?? null,
      // ...
    });
  }
}, [existingEntidade, form]);


Se NÃO tiveres este useEffect com reset, adiciona-o.

Garante que entidadeTipoId vem de existingEntidade.entidadeTipoId.

Confirma também que, no onSubmit:

estás a mandar exactamente o form.getValues() (ou data do handleSubmit),

não estás a reescrever entidadeTipoId noutra função antes de enviar.

Depois de corrigires:

repete o teste de edição de entidade com os logs no backend,

confirma que:

o entidadeTipoId enviado no PATCH corresponde ao que escolheste no select,

o GET seguinte devolve entidadeTipoId e entidade.entidadeTipo.nome atualizados,

e a UI (detalhe + form) mostram o tipo correto.
