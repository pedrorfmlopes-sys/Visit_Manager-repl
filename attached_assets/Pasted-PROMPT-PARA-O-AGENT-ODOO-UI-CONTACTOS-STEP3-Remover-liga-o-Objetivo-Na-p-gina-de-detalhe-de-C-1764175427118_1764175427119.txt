PROMPT PARA O AGENT – ODOO-UI-CONTACTOS-STEP3 (Remover ligação)

Objetivo:
Na página de detalhe de Contacto, permitir remover a ligação ao parceiro Odoo, usando o endpoint já existente:
POST /api/contactos/:id/odoo-link com {"odooPartnerId": null}.

Backend já está pronto. Só precisamos de UI + chamada.
O padrão é igual ao “Unlink” que já fizemos nas Entidades.

1) Adicionar handler handleUnlinkOdooPartnerFromContacto

Ficheiro a editar:
client/src/pages/ContactoDetail.tsx

Perto de handleFetchOdooPartner e handleLinkOdooPartnerToContacto, criar:

const handleUnlinkOdooPartnerFromContacto = async () => {
  if (!contacto?.id) return;

  try {
    // opcional: confirmação simples
    // if (!window.confirm("Remover ligação deste contacto ao Odoo?")) return;

    const response = await fetch(`/api/contactos/${contacto.id}/odoo-link`, {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
      },
      credentials: "include",
      body: JSON.stringify({ odooPartnerId: null }),
    });

    if (!response.ok) {
      throw new Error(`HTTP ${response.status}`);
    }

    // invalidar cache do contacto (React Query)
    queryClient.invalidateQueries({
      queryKey: ["/api/contactos", contactoId],
    });

    // limpar estados relacionados com Odoo
    setOdooPartner(null);
    setOdooPartnerError(null);
    setOdooNotConfigured(false);

    setOdooSearchOpen(false);
    setOdooSearchResults([]);
    setOdooSearchTerm("");
    setOdooSearchError(null);
    setOdooSearchNotConfigured(false);

    // opcional: atualizar contacto local se estiver em state
    if (contacto) {
      contacto.odooPartnerId = null as any;
    }

    toast({
      title: "Ligação removida",
      description: "O contacto deixou de estar ligado ao parceiro Odoo.",
    });
  } catch (error) {
    console.error("[Odoo] Error unlinking partner from contacto:", error);
    setOdooPartnerError("Erro ao remover ligação ao parceiro Odoo.");
    toast({
      title: "Erro",
      description: "Não foi possível remover a ligação ao parceiro Odoo.",
      variant: "destructive",
    });
  }
};


Usa o mesmo queryClient, contactoId e toast já utilizados no ficheiro (padrão igual ao de Entidades).
