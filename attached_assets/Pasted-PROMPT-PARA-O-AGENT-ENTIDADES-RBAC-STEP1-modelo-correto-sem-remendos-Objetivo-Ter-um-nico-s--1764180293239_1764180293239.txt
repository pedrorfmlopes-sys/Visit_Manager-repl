PROMPT PARA O AGENT – ENTIDADES-RBAC-STEP1 (modelo correto, sem remendos)

Objetivo:
Ter um único sítio de verdade para as regras de acesso a Entidades (admin vs agent), e garantir que:

a lista e o detalhe usam exatamente a mesma lógica de permissões;

deixamos de ter erros “Entidade não encontrada” vindos de inconsistências;

o código fica preparado para reaproveitar o mesmo padrão em Visitas e Tarefas.

1) Centralizar a regra de acesso a Entidades

Ficheiro a editar (ou criar, se ainda não existir separado):

Preferência: server/storage/entidadesStorage.ts
(onde estão getEntidade, listEntidades ou funções equivalentes)

Tarefas:

Dentro deste ficheiro, cria uma função auxiliar para construir o where de acesso:

import { and, or, eq } from "drizzle-orm";
// ... restantes imports

function buildEntidadeAccessWhere(
  empresaId: string,
  userId: string,
  userRole: string
) {
  if (userRole === "admin") {
    // Admin vê todas as entidades da empresa
    return eq(entidades.empresaId, empresaId);
  }

  // Agent: só entidades da empresa em que é criador ou assigned
  return and(
    eq(entidades.empresaId, empresaId),
    or(
      eq(entidades.createdByUserId, userId),
      eq(entidades.assignedUserId, userId)
    )
  );
}


Usa os nomes de campos reais da tabela entidades (empresaId, createdByUserId, assignedUserId ou equivalentes).
Se os nomes forem ligeiramente diferentes, ajusta aqui.

2) Garantir que getEntidade usa este helper

Ainda em entidadesStorage.ts, localiza a função de detalhe, algo como:

export async function getEntidade(
  id: string,
  empresaId: string,
  userId: string,
  userRole: string
) {
  // ...
}


Atualiza o where da query para usar o helper:

export async function getEntidade(
  id: string,
  empresaId: string,
  userId: string,
  userRole: string
) {
  const whereClause = and(
    eq(entidades.id, id),
    buildEntidadeAccessWhere(empresaId, userId, userRole)
  );

  const entidade = await db.query.entidades.findFirst({
    where: whereClause,
    // with, etc. se já existirem
  });

  return entidade;
}


Remove qualquer lógica duplicada de RBAC dentro desta função (deve ficar sempre via buildEntidadeAccessWhere).
