O teu relatório diz que:

1. Verificar o return principal de AdminEmpresa

Quero que:

No ficheiro client/src/pages/AdminEmpresa.tsx, confirmes que o return principal da página NÃO tem nenhum JSX das secções fora de renderCurrentSection().

Ou seja, o return deve ter apenas algo neste formato:

return (
  <Form {...form}>
    {/* barra de secções */}
    <SectionNavigation
      currentSection={currentSection}
      onSectionClick={handleSectionClick}
    />

    {/* ✅ só 1 secção */}
    {renderCurrentSection()}
  </Form>
);


E não deve existir nada como:

{currentSection === "empresa" && ...}
{currentSection === "visitas" && ...}
// ou blocos tipo <EmpresaSection /> fora de renderCurrentSection


Se ainda houver código antigo a renderizar as secções directamente no return, remove-o e garante que tudo passa por renderCurrentSection().

2. Garantir que currentSection muda mesmo ao clicar

Garante que estás a ler o section da URL apenas num sítio, de forma consistente.
Por exemplo (conceito, ajusta ao router real):

const [location, navigate] = useLocation();

const currentSection = sectionFromUrl;


Ou, se usares useState, certifica-te de que o estado e a URL estão sempre sincronizados.

Garante que TODOS os botões que mudam de secção chamam handleSectionClick com o id correcto:

barra de secções no topo de /admin/empresa;
