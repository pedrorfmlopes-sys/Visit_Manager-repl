PROMPT PARA O AGENT – ODOO-VISITAS-LEAD-STEP1

Objetivo:
Garantir que, na página de detalhe da Visita, o botão “Criar lead no Odoo”:

cria mesmo uma crm.lead no Odoo,

guarda o odooLeadId na tabela visitas,

e o card da visita mostra o estado correto (ou o erro real, se falhar).

1) Backend – createOdooLead com uid correto

Ficheiro: server/integrations/odooClient.ts

Localiza a função createOdooLead (já deve existir).
Garante que faz:

export async function createOdooLead(
  conn: OdooConnection,
  payload: Record<string, any>
): Promise<number> {
  const uid = await authenticateOdoo(conn);

  const leadId = await callOdooJsonRpc<number>(conn, {
    method: "call",
    params: {
      service: "object",
      method: "execute_kw",
      args: [
        conn.dbName,
        uid,
        conn.apiKey,
        "crm.lead",
        "create",
        [payload],
      ],
    },
  });

  if (typeof leadId !== "number") {
    throw new Error(`Odoo create lead did not return numeric id (got: ${String(leadId)})`);
  }

  return leadId;
}


Usar sempre uid (não username) como 2.º argumento.

2) Backend – rota POST /api/integrations/odoo/visitas/:id/create-lead

Ficheiro: server/routes/integrations/odoo.ts

Localiza a rota POST "/visitas/:id/create-lead".

Garante uma implementação nesta linha:

odooIntegrationsRouter.post(
  "/visitas/:id/create-lead",
  isAuthenticated,
  async (req: any, res) => {
    try {
      const { empresaId } = await getUserContext(req);
      const visitaId = req.params.id;

      if (!empresaId) {
        return res.status(400).json({
          success: false,
          message: "Empresa em falta no contexto.",
        });
      }

      // Buscar visita + entidade + contacto
      const visita = await db.query.visitas.findFirst({
        where: and(eq(visitas.id, visitaId), eq(visitas.empresaId, empresaId)),
        with: {
          entidade: true,
          contacto: true,
        },
      });

      if (!visita) {
        return res.status(404).json({
          success: false,
          message: "Visita não encontrada.",
        });
      }

      const conn = await getOdooConnectionForEmpresa(empresaId);

      // Construir payload mínimo para crm.lead
      const nomeEntidade = visita.entidade?.nome ?? "";
      const nomeContacto =
        visita.contacto?.nome ??
        visita.entidade?.nome ??
        "Lead Visit Manager";

      const payload: Record<string, any> = {
        name: visita.assunto || `Visita – ${nomeEntidade || nomeContacto}`,
        partner_name: nomeEntidade || undefined,
        contact_name: nomeContacto,
        email_from:
          visita.contacto?.email ??
          visita.entidade?.email ??
          undefined,
        phone:
          visita.contacto?.telefone ??
          visita.entidade?.telefone ??
          undefined,
        // podes acrescentar mais campos depois (description, user_id, etc.)
      };

      const leadId = await createOdooLead(conn, payload);

      // Guardar o leadId na visita
      await db
        .update(visitas)
        .set({ odooLeadId: String(leadId) })
        .where(and(eq(visitas.id, visitaId), eq(visitas.empresaId, empresaId)));

      return res.json({
        success: true,
        leadId,
      });
    } catch (error: any) {
      console.error("[Odoo] create lead from visita error:", {
        message: error?.message,
        stack: error?.stack,
      });

      return res.status(500).json({
        success: false,
        error: "Odoo create lead error",
        message:
          error?.message ?? "Erro ao criar lead no Odoo a partir da visita.",
      });
    }
  }
);


Importante: usar visitas importado de ../shared/schema, como já fazemos noutros pontos.
