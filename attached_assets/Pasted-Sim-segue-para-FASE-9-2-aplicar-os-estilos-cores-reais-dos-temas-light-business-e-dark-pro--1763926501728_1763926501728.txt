Objetivo:
Quando empresa.theme === "light-business" → UI clara, estilo SaaS moderno.
Quando empresa.theme === "dark-pro" → UI escura, estilo app pro.

Importante: não mexer em lógica de negócio (visitas, tarefas, áudio, marcas, etc.). Só styling/tema.

Tarefas:

1) Ligar o theme da empresa ao frontend
- Já temos /api/admin/empresa a devolver theme e /api/auth/user a devolver empresa.
- Em client/src/hooks/useAuth.ts já devolves empresa.
- Em client/src/App.tsx adiciona um useEffect que, sempre que empresa.theme mudar:
  - se theme === "dark-pro":
      - adicionar a classe "dark" ao document.documentElement
      - definir data-theme="dark-pro" em document.documentElement
  - se theme === "light-business":
      - remover a classe "dark"
      - definir data-theme="light-business"

2) Definir variáveis de tema no CSS global
No ficheiro global de estilos (por ex. client/src/index.css ou equivalente), definir:

:root[data-theme="light-business"] {
  --bg: #F5F7FB;
  --bg-card: #FFFFFF;
  --bg-nav: #FFFFFF;
  --primary: #2563EB;
  --primary-soft: #DBEAFE;
  --text-main: #111827;
  --text-muted: #6B7280;
  --border-subtle: #E5E7EB;
}

:root[data-theme="dark-pro"] {
  --bg: #020617;
  --bg-card: #111827;
  --bg-nav: #020617;
  --primary: #6366F1;
  --primary-soft: #1E293B;
  --text-main: #E5E7EB;
  --text-muted: #9CA3AF;
  --border-subtle: #1F2937;
}

Depois, liga isto às classes/utilitários que a app usa, por exemplo:

body {
  background-color: var(--bg);
  color: var(--text-main);
}

.elevated-card {
  background-color: var(--bg-card);
  border: 1px solid var(--border-subtle);
}

.nav-bar {
  background-color: var(--bg-nav);
}

.btn-primary {
  background-color: var(--primary);
  color: white;
}

Se já houver um sistema de tokens (bg-background, text-foreground, etc.), adapta as variáveis para alimentar esses tokens em vez de criar classes novas.
