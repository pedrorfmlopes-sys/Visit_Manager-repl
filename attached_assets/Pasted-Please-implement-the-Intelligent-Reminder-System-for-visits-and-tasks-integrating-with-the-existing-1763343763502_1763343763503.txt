Please implement the Intelligent Reminder System for visits and tasks, integrating with the existing entities, visitas, tarefas, AI email module, offline sync, and RBAC.

⭐ 1. NEW: Reminder Engine (Backend)

Create a backend reminder engine (non-real-time, trigger-based) that evaluates reminders whenever:

the user opens the app

the user returns online

a visit is created/updated

a task is created/updated

daily at the first query (local trigger)

The reminder engine should:

A) Generate visit reminders

For each entity:

If last visit was > 30 days → Reminder:
“Já passaram 30 dias desde a última visita a {entidade}. Pretende agendar uma nova visita?”

If entity has tasks pending and no new visit scheduled → Reminder:
“Existem tarefas pendentes para {entidade} sem visita agendada. Deseja criar follow-up?”

If entity has IA Summary with explicit next steps and they are not done → Reminder:
“A IA sugeriu um follow-up para {entidade}. Deseja criar tarefa ou agendar visita?”

B) Generate task reminders

For each tarefa:

If overdue:
“A tarefa {tarefa.titulo} está atrasada. Reagendar?”

If due date is tomorrow:
“A tarefa {tarefa.titulo} vence amanhã. Deseja antecipar ou preparar follow-up?”

If assigned to user and no activity in > 7 days:
“Esta tarefa parece parada. Quer atualizá-la?”

C) Generate AI-suggested reminders

Use the existing visit AI Summary and entity metadata to produce high-value follow-ups:

interest keyword detection

product/brand delivered follow-up

pending catalogs or samples

stalled opportunities

Use OpenAI ONLY for suggestion generation, NOT for scheduling.

AI prompt inputs:

last visits

visit IA summary

tasks

entity details

agent performance

brand delivered list

Output: short suggestions.
