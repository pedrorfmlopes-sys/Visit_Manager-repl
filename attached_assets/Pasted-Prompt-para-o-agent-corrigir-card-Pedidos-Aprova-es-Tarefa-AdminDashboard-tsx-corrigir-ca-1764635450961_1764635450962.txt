Tarefa – AdminDashboard.tsx: corrigir card "Pedidos / Aprovações"

No ficheiro client/src/pages/AdminDashboard.tsx (Dashboard Admin), procura o useQuery que está a carregar os pedidos Odoo para o card “Pedidos / Aprovações`.
Neste momento está algo como:

const {
  data: odooRequests,
  isLoading: odooRequestsLoading,
  isError: odooRequestsError,
} = useQuery<OdooContactRequest[]>({
  queryKey: ["/api/odoo/contact-requests", "dashboard"],
});


Substitui esse bloco por este, com queryFn definido e default []:

const {
  data: odooRequests = [],
  isLoading: odooRequestsLoading,
  isError: odooRequestsError,
} = useQuery<OdooContactRequest[]>({
  queryKey: ["/api/odoo/contact-requests", "dashboard"],
  queryFn: async () => {
    const res = await fetch("/api/odoo/contact-requests");
    if (!res.ok) {
      throw new Error("Failed to fetch Odoo contact requests");
    }
    const json = await res.json();
    if (!json.success) {
      throw new Error(json.message || "Erro ao carregar pedidos Odoo");
    }
    return json.data as OdooContactRequest[];
  },
});


Mantém depois a lógica já existente que calcula:

const pendingOdooRequests = odooRequests?.filter((r) => r.estado === "pendente").length ?? 0;

const totalRelevantOdooRequests = pendingOdooRequests + inProgressOdooRequests;
