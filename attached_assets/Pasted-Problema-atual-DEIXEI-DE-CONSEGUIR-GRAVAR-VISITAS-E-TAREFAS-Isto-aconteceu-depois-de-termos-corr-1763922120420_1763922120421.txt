- Suspeita forte:

1) Verificar schemas Zod de VISITAS e TAREFAS

- `insertVisitaSchema`
- `insertTarefaSchema` (ou nomes parecidos)

O que eu quero é:

- Para VISITAS:
  - `insertVisitaSchema` deve fazer `omit()` de:
    - `id`

    - entidadeId, contactoId (se existir), dataVisita, tipoVisita, notas, etc.
- Para TAREFAS:
  - `insertTarefaSchema` também deve fazer `omit()` de:
    - `id`
    - `empresaId`      ✅ (backend injeta)
    - `createdAt`
    - `updatedAt`

    - título, descrição, visitaId/entidadeId, dueDate, etc.

Exemplo do que quero (pseudo):

// VISITAS
export const insertVisitaSchema = createInsertSchema(visitas).omit({
  id: true,
  empresaId: true,   // ✅ backend
  createdAt: true,
  updatedAt: true,
});

// TAREFAS
export const insertTarefaSchema = createInsertSchema(tarefas).omit({
  id: true,
  empresaId: true,   // ✅ backend
  createdAt: true,
  updatedAt: true,
});
