FASE AUDIO-BACKEND-01 – Corrigir erro 500 no /api/crm/leads/ai/transcribe

- Quando clico "Transcrever áudio" numa VISITA:
  - O frontend chama POST /api/crm/leads/ai/transcribe.
  - O servidor responde HTTP 500 com body:
    {"success":false,"message":"Falha ao transcrever áudio. Por favor, tenta novamente."}

- O VisitaForm.tsx já está correto e usa o hook useAudioTranscription;
  o erro vem do backend.

Objetivo:
- Descobrir a causa real do erro dentro do endpoint /api/crm/leads/ai/transcribe.
- Corrigir de forma a que:
  - Em sucesso → devolve { success:true, text:"..." } (status 200).
  - Em falha "esperada" (ex: IA não configurada) → devolve { success:false, message:"..." } com status 200 ou 400.
  - Deixa de devolver 500 genérico.

   POST /api/crm/leads/ai/transcribe

   - Ver como é chamada a função transcribeAudio() de server/openai.ts.
   - No catch atual, adicionar logs detalhados:
