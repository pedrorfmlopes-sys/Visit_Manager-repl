Adiciona um useQuery (ou hook já existente) para carregar tipos de entidade ativos:

Importante:

Usa = [] no destructuring para garantir que entidadeTipos nunca é undefined.

No select de tipos:

Garante que o código é algo nesta linha (pseudo):

{entidadeTipos.length > 0 ? (
  <Select
    // value/field ligado a entidadeTipoId
    // options = entidadeTipos.map(t => ({ value: t.id, label: t.nome }))
  />

  <p className="text-sm text-muted-foreground">
    Sem tipos definidos – configure em Definições → Entidades.
  </p>
