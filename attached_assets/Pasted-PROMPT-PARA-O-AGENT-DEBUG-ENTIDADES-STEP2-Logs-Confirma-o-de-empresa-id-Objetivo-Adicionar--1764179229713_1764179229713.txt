Objetivo:
Adicionar logs no backend para perceber por que razão storage.getEntidade(...) está a devolver null quando clicamos num card de Entidade.

1) Adicionar logs na rota /api/entidades/:id

Ficheiro a editar:
server/routes.ts (onde está definida a rota app.get('/api/entidades/:id', ...))

Tarefas:

Na rota /api/entidades/:id, logo após o getUserContext(req) e antes de chamar storage.getEntidade, adiciona:

console.log("[Entidades] GET /api/entidades/:id", {
  paramId: req.params.id,
  userId,
  userRole,
  empresaId,
});


Logo antes do bloco:

if (!entidade) {
  return res.status(404).json({ message: "Entidade not found" });
}


adiciona:

console.log("[Entidades] storage.getEntidade result is null", {
  paramId: req.params.id,
  userId,
  userRole,
  empresaId,
});


Não alteres mais nada nesta rota por agora.

2) Adicionar log dentro de storage.getEntidade

Ficheiro a editar:
server/storage.ts (ou o ficheiro onde está definida getEntidade(id, empresaId, userId, userRole) – usar o nome real que já existe).

Tarefas:

Dentro da função getEntidade(...), antes de fazer a query à BD (db.select().from(entidades)...), adiciona:

console.log("[storage.getEntidade] called with", {
  id,
  empresaId,
  userId,
  userRole,
});


Depois de obter o resultado da query (logo antes do return entidade), adiciona algo como:

console.log("[storage.getEntidade] DB result", {
  id,
  empresaId,
  found: !!entidade,
});


Mantém os nomes dos parâmetros exatamente como estão hoje na função, ajusta apenas o objeto do console.log se os nomes forem ligeiramente diferentes.
