Please implement a complete Visit PDF Export system for the application.

This module must generate a professional-quality PDF report for any visit, using a backend API endpoint and a frontend download button.

1. Backend — PDF Generation Endpoint

Create a new endpoint:

GET /api/visitas/:id/pdf

This should:

Fetch the visit, including:

entidade (with enrichment fields: logoUrl, domain, industry, description, social links)

contacto principal (if any)

user who created the visit

tarefas linked to this visit

IA summary field

media:

photos

videos (list only, no embed)

audio notes

Generate a PDF with:

Header:

entidade logo (if exists)

entidade name + type

visit date

Section 1: Entidade details

name

type

NIF

address

phone, email, website

social links (LinkedIn, FB, IG, X)

Section 2: Contacto details (if exists)

name, email, phone

Section 3: Visit Information

date

notes

IA summary (highlighted section)

GPS coordinates (if present)

Section 4: Tarefas desta visita
For each task:

status badge

titulo

descricao

due date

assigned user

Section 5: Media

display photos (scaled)

list links to videos

link to audio file

Footer:

“Generated by Divitek Visit Manager”

timestamp

Use an HTML template rendered via a server-side PDF library (ex: @react-pdf/renderer, Puppeteer, or similar depending on project setup).

2. Frontend — PDF Download Button

In VisitaDetail page:

Add a new button:

🖨️ Exportar PDF

On click:

call GET /api/visitas/:id/pdf

download the PDF file with filename:
Visita-{entidade.nome}-{data}.pdf

Button must be disabled if:

offline

visit has no data loaded

3. Offline Mode

If offline:

show a message:
“A exportação PDF só está disponível quando estiver online.”

disable the button

(Do NOT store PDFs offline.)

4. Permissions (RBAC)

Admins: can export PDF from any visit

Agents: can only export their own visits or visits assigned to them

Unauthorized → return 403

5. Quality Requirements

Clean, modern layout

Use entidade logo if available

Use consistent spacing, typography and Divitek style

Support large amounts of text without breaking

Scale images correctly

PDF must render correctly on mobile and desktop

6. Testing & Final Checks

Verify:

PDF generates without errors even if some fields are null

Works in Chrome, Edge, Safari

Photo scaling stable

IA summary formatted correctly

Tasks sorted by due_date

No “empty string” database errors

Timeout-safe for large reports

Proceed.
