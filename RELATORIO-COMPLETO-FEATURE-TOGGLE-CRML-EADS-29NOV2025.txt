ARQUITETURA FINAL DO SISTEMA
================================================================================

CAMADAS DE PROTECCAO:

1. DATABASE
   └─ empresas.crmLeadsEnabled: boolean
      - Fonte da verdade
      - Valor defaults a false
      - Admin pode toggle em /admin/empresa

2. BACKEND API
   ├─ GET /api/auth/user
   │  └─ Retorna: { ..., crmLeadsEnabled: boolean | false }
   │
   ├─ GET /api/crm/leads
   │  └─ Protegido por: assertLeadsEnabled(empresaId)
   │     Se OFF → throws error
   │
   └─ POST /api/integrations/odoo/visitas/{id}/create-lead
      └─ Protegido por: assertLeadsEnabled(empresaId)
         Se OFF → throws error

3. FRONTEND HOOK
   └─ useAuth() → { empresa: { crmLeadsEnabled: boolean | undefined } }
      - Acesso type-safe
      - Propaga mudancas a todos componentes

4. FRONTEND COMPONENTS
   ├─ BottomNav
   │  └─ {leadsEnabled && <Link to="/leads" />}
   │     Menu item desaparece quando OFF
   │
   ├─ EntidadeDetail
   │  └─ {leadsEnabled && <Card>Leads</Card>}
   │     Card desaparece quando OFF
   │
   ├─ ContactoDetail
   │  └─ {leadsEnabled && <Card>Leads</Card>}
   │     Card desaparece quando OFF
   │
   └─ VisitaDetail
      └─ {leadsEnabled && <Card>Odoo</Card>}
         Card desaparece quando OFF

FLUXO DE SINCRONIZACAO:

  Database crmLeadsEnabled = false
    ↓
  Admin em /admin/empresa → Toggle OFF
    ↓
  PATCH /api/empresas/xxx { crmLeadsEnabled: false }
    ↓

    ↓
  GET /api/auth/user → Retorna crmLeadsEnabled = false
    ↓
  useAuth hook atualizado
    ↓
  React re-render em TODOS componentes
    ├─ BottomNav: /leads item desaparece
    ├─ EntidadeDetail: Leads card desaparece
    ├─ ContactoDetail: Leads card desaparece
    └─ VisitaDetail: Odoo card desaparece

RESULTADO FINAL:
  ✅ Sistema inteiro comporta-se como "Leads disabled"
  ✅ Zero referencias a Leads visivel
  ✅ Zero API calls a /api/crm/leads
  ✅ Zero possibilidade de criar leads manualmente
