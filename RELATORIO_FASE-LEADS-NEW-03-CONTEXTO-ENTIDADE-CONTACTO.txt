NOVO codigo:
  const handleNovoLeadVisita = () => {
    if (!visita?.id || !visita.entidadeId) {
      toast({ ... });
      return;
    }

    const contactoIdFromVisita: string | null =
      visita?.contactoId ||
      (Array.isArray(visita?.contactosPresentes) && visita.contactosPresentes[0]?.id) ||
      null;

    if (!contactoIdFromVisita) {
      toast({ ... });
      return;
    }

    const returnTo = `/admin/visitas/${visita.id}`;
    const url = `/admin/leads/new` +
      `?visitaId=${visita.id}` +
      `&entidadeId=${visita.entidadeId}` +
      `&contactoId=${contactoIdFromVisita}` +
      `&returnTo=${encodeURIComponent(returnTo)}`;
    setLocation(url);
  };

LOGICA:
1. Validar visita.id + visita.entidadeId
2. Extrair contactoId:
   - Primeiro tenta visita.contactoId (single contact, legacy)
   - Se vazio, usa primeiro de contactosPresentes (pivot table)
3. Se entidade ou contacto ausente → toast error, NAO navega
4. Se OK → navega com URL completa

RESULTADO:
- URL: /admin/leads/new?visitaId=...&entidadeId=...&contactoId=...&returnTo=...

- returnTo: URL encoded, para voltar após criação
