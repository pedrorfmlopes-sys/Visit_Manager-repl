2. CORES E STYLING
================================================================================

Cor escolhida: AMBER (amarelo/laranja)
- text-amber-600 (light mode)
- dark:text-amber-400 (dark mode)
- Font: font-medium (ligeiramente mais destacado)

Justificação:
- GREEN é usado para "Áudio gravado pronto" (estado final)
- AMBER usado para "A gravar" (estado transitório/em curso)
- Diferencia claramente os dois estados
- Ambos visíveis em light e dark mode

================================================================================
7. NOTAS TÉCNICAS
================================================================================

Por que AMBER em vez de outra cor?
- RED: Conflito com "Parar" button (destructive)
- GREEN: Reservado para "Áudio gravado" (estado final, pronto)
- BLUE: Muito suave para timer ativo
- AMBER: Perfeito - indica ação em curso, temporário

Por que colocado ANTES de "Áudio gravado"?
- Ambos são condicionais:
  - isRecording === true → "A gravar há Xs"
  - hasAudio && !isRecording === true → "Áudio gravado pronto"
- Nunca aparecem simultaneamente
- Ordem clara: ativo (AMBER) → concluído (GREEN)
