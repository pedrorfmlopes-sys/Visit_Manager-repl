4. FLUXO DE USO - DEPOIS DA REFATORIZAÇÃO
================================================================================

Utilizador quer transcrever:

1. Clicka "Gravar" em "Ditar Anotações"
   → audio.startRecording()
   → Abre micro, começa a gravar
   → Botão muda para "Parar" (destructive red)

2. Clicka "Parar"
   → audio.stopRecording()
   → Para gravação, guarda Blob
   → hasAudio = true (Botão "Transcrever áudio" ativa)

3. Clicka "Transcrever áudio"
   → const text = await audio.transcribe()
   → Envia para /api/visitas/ai/transcribe
   → form.setValue("notas", text)
   → Toast "Áudio transcrito"
   → Texto aparece nas notas

ALTERNATIVA: Clicka "Ficheiro" para escolher ficheiro

1. Clicka "Ficheiro"
   → const text = await audio.selectFileAndTranscribe()
   → Abre file picker <input type="file" accept="audio/*">
   → Utilizador escolhe ficheiro
   → Envia para /api/visitas/ai/transcribe
   → form.setValue("notas", text)
   → Toast "Ficheiro transcrito"
   → Texto aparece nas notas
