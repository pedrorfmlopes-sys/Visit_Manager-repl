1. O PROBLEMA REAL (Root Cause)
================================================================================

ERRO IDENTIFICADO: HTML Form Aninhadas
  
  AdminMarcas.tsx estava usando:
  - <form onSubmit={...}> para criar marcas
  - <form onSubmit={...}> para editar marcas
  
  MAS AdminMarcas.tsx é renderizado DENTRO de AdminEmpresa.tsx, que tem:
  - <Form> component (shadcn) que gera <form> internamente
  
  Resultado:
  ✗ <form> aninhada dentro de <form> = ERRO DE HTML
  ✗ Browser console error: "validateDOMNesting(...): <form> cannot appear as a descendant of <form>"
  ✗ React Hook Form hooks chamados fora de contexto
  ✗ Form submission não funciona

Log do Browser (prova do erro):
  "Warning: Invalid hook call. Hooks can only be called inside of the body of a function component"
  "Warning: A component is changing an uncontrolled input to be controlled"
  "validateDOMNesting(...): <form> cannot appear as a descendant of <form>"

Impacto:
  - POST /api/admin/marcas era chamado MAS com erro silencioso
  - Invalidate queries não funcionava por causa do erro
  - Usuario via "Marca criada com sucesso" (toast) MAS marca não aparecia
