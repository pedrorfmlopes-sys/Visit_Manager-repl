PROBLEMA ORIGINAL
================================================================================

O servidor crashava com:
  TypeError: Cannot read properties of undefined (reading 'user')
  at handleGetUser (server/routes/authRoutes.ts:69:34)

Causa: req.session era undefined porque o middleware de sessao (express-session)
       NAO estava configurado antes das rotas serem registadas.

================================================================================
ANALISE
================================================================================

1. Ficheiro server/replitAuth.ts
   - Exporta setupAuth(app) que configura:
     - express-session com PostgreSQL store
     - passport.js com Replit OAuth
     - Rotas /api/login, /api/callback, /api/logout

2. Ficheiro server/index.ts (ANTES)
   - NAO chamava setupAuth(app)
   - Resultado: req.session undefined em todos os handlers

3. Ficheiro server/routes/authRoutes.ts (ANTES)
   - Definia /api/login duplicado (conflito com replitAuth.ts)

================================================================================
FLUXO DE AUTENTICACAO CORRIGIDO
================================================================================

1. Utilizador acede a /
2. Frontend chama GET /api/auth/me (via useAuth hook)
3. Se nao autenticado: 401 {"user":null} -> mostra Landing.tsx
4. Utilizador clica "Entrar" -> window.location.href = "/api/login"
5. /api/login (replitAuth.ts) faz redirect 302 para Replit OAuth
6. Apos OAuth: callback para /api/callback -> redirect para /
7. Frontend refetch /api/auth/me -> agora devolve 200 com user
8. isAuthenticated = true -> mostra Dashboard

================================================================================
ENDPOINTS DE AUTENTICACAO
================================================================================

Endpoint             | Fonte          | Comportamento
---------------------|----------------|----------------------------------------
GET /api/auth/me     | authRoutes.ts  | 401 {user:null} ou 200 {user:{...}}
GET /api/auth/user   | authRoutes.ts  | Alias de /api/auth/me
POST /api/auth/logout| authRoutes.ts  | Destroi sessao, {ok:true}
GET /api/login       | replitAuth.ts  | Redirect 302 para Replit OAuth
GET /api/callback    | replitAuth.ts  | Callback OAuth, redirect para /
GET /api/logout      | replitAuth.ts  | Logout OAuth completo
