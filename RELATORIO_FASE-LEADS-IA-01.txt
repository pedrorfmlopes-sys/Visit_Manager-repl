2. BACKEND - ENDPOINTS CRIADOS
================================================================================

Ficheiro Alterado: server/routes/crmLeads.ts

1. POST /api/crm/leads/ai/transcribe
   - Recebe: multipart/form-data com arquivo "file" (áudio)
   - Validações:
     * Verifica se empresaId tem Leads ativado
     * Rejeita se não houver arquivo
     * Limite de 25MB por arquivo
   - Lógica:
     * Reutiliza transcribeAudio() do openai.ts
     * Escreve arquivo em temp, transcreve, limpa temp
     * Responde: { success: true, text: "...transcrição..." }
   - Em erro: Retorna { success: false, message: "..." }
   - Logs: "[CRM Leads AI] Transcription success"

2. POST /api/crm/leads/ai/summarize
   - Recebe: JSON { text: string, titulo?: string }
   - Validações:
     * Verifica se empresaId tem Leads ativado
     * Rejeita se text vazio
   - Lógica:
     * Reutiliza getOpenAIClient() do openai.ts
     * Usa modelo gpt-4o-mini
     * Prompt: "Melhora este texto de lead, tornando-o mais profissional"
     * Responde: { success: true, text: "...texto melhorado..." }
   - Em erro: Retorna { success: false, message: "..." }
   - Logs: "[CRM Leads AI] Summarize success"

Segurança:
✅ Ambos endpoints requerem isAuthenticated
✅ Ambos validam se Leads está ativado para a empresa
✅ Sem exposição de stack traces nos erros
✅ Limites de tamanho implementados

4. FLUXOS DE USO
================================================================================

Fluxo 1: Transcrever Áudio
1. User clica botão "Dictar"
2. Sistema abre file picker do browser
3. User seleciona arquivo de áudio (mp3, wav, webm, etc)
4. Sistema faz upload e transcrição
5. Texto transcrito é adicionado ao campo descrição
6. Toast de sucesso

Fluxo 2: Melhorar Texto com IA
1. User escreve ou cola texto na descrição
2. User clica botão "IA"
3. Sistema envia texto para processamento
4. IA melhora e estrutura o texto
5. Campo descrição é atualizado com versão melhorada
6. Toast de sucesso

Fluxo 3: Combinado
1. User grava áudio → transcreve com Dictar
2. User clica IA para melhorar transcrição
3. Resultado: texto transcrito + polido
