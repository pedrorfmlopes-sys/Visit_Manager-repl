FUNCIONALIDADE
================================================================================

FLUXO:

1. User acede a /admin/leads/{id}
   → Lead carregado com odooLeadId

2. OdooAttachmentsSection renderizado:
   a) Se !odooLeadId: Mensagem "ainda não existe no Odoo"
   b) Se odooLeadId: fetch /api/crm/leads/{id}/odoo/attachments
      - Loading: "A carregar..."
      - Error: "Erro ao carregar..."
      - Empty: "Sem anexos..."
      - Success: Card com chips

3. Cada anexo em AttachmentChip:
   - Exibe: nome + tamanho + ícones
   - Click: Abre download no Odoo (target="_blank")
   - Hover: Destaca-se (bg-slate-200 dark:hover:bg-slate-700)

TAMANHOS FORMATADOS:
   - < 1KB: "123B"
   - < 1MB: "45.6KB"
   - >= 1MB: "1.2MB"

================================================================================
DADOS OBTIDOS DO BACKEND
================================================================================

Endpoint: GET /api/crm/leads/:id/odoo/attachments

Resposta Success:
{
  "success": true,
  "attachments": OdooLeadAttachment[]
}

Resposta No Lead:
{
  "success": false,
  "message": "Lead não encontrado"
}

Resposta No odooLeadId:
{
  "success": true,
  "attachments": []
}

Frontend Handling:
  - data.success === true → render cards
  - isError → mostrar erro
  - attachments.length === 0 → mensagem vazia
  - !odooLeadId → guard antes de fetch
