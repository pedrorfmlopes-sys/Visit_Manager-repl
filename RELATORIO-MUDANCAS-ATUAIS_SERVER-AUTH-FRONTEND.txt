COLUNA ANTIGA (crmLeadsEnabled):
  - Tipo: boolean (coluna direta na tabela)
  - Lookup: O(1) - acesso direto
  - Default: false
  - Quando existe: sempre (schema antigo)

JSONB NOVO (features.leadsEnabled):
  - Tipo: object { leadsEnabled?: boolean }

  - Default: true
  - Quando existe: novo schema
