3. FLUXO DE DADOS (Frontend)
================================================================================

CENARIO 1: Modal "Novo lead desta visita"

Abertura modal:
  1. Estado inicial: leadForm.marcasIds = []
  2. useQuery carrega marcas[] da empresa
  3. Popover mostra dropdown com search + checkboxes

Usuario seleciona 2 marcas (ex: "Ritmonio", "Bette"):
  1. leadForm.marcasIds = ["marca-1-uuid", "marca-2-uuid"]
  2. Button mostra "2 marcas selecionadas"

Submit ("Criar lead"):
  1. POST body: { marcasIds: ["marca-1-uuid", "marca-2-uuid"], ... }
  2. Backend aceita, cria leads_marcas, atualiza campo marca
  3. Toast "Lead criado"
  4. Reset: leadForm.marcasIds = []
  5. Modal fecha

CENARIO 2: Edicao lead (/admin/leads/:id)

Carregamento:
  1. GET /api/crm/leads/:id retorna lead com marcas: [{ id, nome }, ...]
  2. form.marcasIds = lead.marcas?.map((m) => m.id) = ["marca-1", "marca-2"]
  3. Multi-select mostra "2 marcas selecionadas" (pre-preenchido)

Usuario edita (remove marca-1, adiciona marca-3):
  1. form.marcasIds = ["marca-2", "marca-3"]
  2. Button atualiza para "2 marcas selecionadas"

Submit ("Guardar alteracoes"):
  1. PATCH body: { marcasIds: ["marca-2", "marca-3"], ... }
  2. Backend DELETE antigas em leads_marcas, INSERT novas
  3. Backend atualiza campo marca = "Bette, Kora"
  4. Toast "Lead atualizado"
  5. Cache invalidado - next GET mostra dados atualizados
