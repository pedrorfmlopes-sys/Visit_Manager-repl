FLUXO DA ROTA
================================================================================

1. AUTENTICAÇÃO E VALIDAÇÃO DE LEAD
   ✓ getUserContext(req) → empresaId
   ✓ assertLeadsEnabled(empresaId)
   ✓ const id = req.params.id
   ✓ console.log inicio

2. CARREGAR LEAD DA BD
   ✓ db.query.leads.findFirst({
       where: and(eq(leads.id, id), eq(leads.empresaId, empresaId)),
       columns: { id, odooLeadId }
     })
   ✓ Se não encontrado: 404 "Lead não encontrado"

3. VALIDAR SYNC COM ODOO
   ✓ if (!lead.odooLeadId):
       400 "Este lead ainda não está sincronizado com o Odoo."

4. VALIDAR FICHEIRO
   ✓ if (!req.file):
       400 "Nenhum ficheiro enviado."

5. VALIDAR TAMANHO
   ✓ MAX_FILE_SIZE = 10 * 1024 * 1024 (10 MB)
   ✓ if (buffer.length > MAX_FILE_SIZE):
       400 "Ficheiro demasiado grande (máx. 10 MB)."

6. OBTER DADOS DO FICHEIRO
   ✓ const file = req.file
   ✓ const buffer = file.buffer
   ✓ const fileName = file.originalname
   ✓ const mimetype = file.mimetype || null

7. LOG DOS DADOS
   ✓ console.log "[CRM Leads] Upload file details" com
     { leadId, fileName, size, mimetype }

8. CHAMAR ODOOCLIENT
   ✓ const attachmentId = await createLeadAttachment({
       empresaId,
       odooLeadId: lead.odooLeadId,
       fileName,
       mimetype,
       buffer,
     })

9. LOG DE SUCESSO
   ✓ console.log "[CRM Leads] POST /:id/odoo/attachments success" com
     { leadId, odooLeadId, attachmentId }

10. RESPONDER
    ✓ res.json({
        success: true,
        attachmentId,
      })

================================================================================
MIDDLEWARE MULTER
================================================================================

Localização: Linha 21 (topo de registerCrmLeadsRoutes)

Configuração:
  const upload = multer({
    storage: multer.memoryStorage(),
    limits: { fileSize: 25 * 1024 * 1024 }
  })

Características:
  ✓ Memory storage: arquivo em RAM (não em disco)
  ✓ Limit global: 25 MB (multer validation)
  ✓ Validação de upload: upload.single("file")
  ✓ Reutilizado por: POST /api/crm/leads/:id/odoo/attachments
  ✓ Reutilizado por: POST /api/ai/leads/transcribe (já existia)
  ✓ Reutilizado por: POST /api/ai/leads/summarize (se houver)

Limite de Ficheiro (aplicação):
  ✓ MAX_FILE_SIZE = 10 * 1024 * 1024 (10 MB)
  ✓ Validação dupla:
    1. Multer valida (25 MB global)
    2. Aplicação valida (10 MB para Odoo)

Fluxo Multer:
  1. Recebe multipart/form-data
  2. Processa single file com fieldName "file"
  3. Carrega em buffer na memória
  4. Passa req.file ao handler

Dados Disponíveis em req.file:
  - buffer: Buffer (conteúdo binário)
  - originalname: string (nome original)
  - fieldname: string ("file")
  - mimetype: string (content-type)
  - size: number (tamanho em bytes)
  - encoding: string
