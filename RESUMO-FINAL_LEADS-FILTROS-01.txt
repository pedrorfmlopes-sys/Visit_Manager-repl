MUDANCAS IMPLEMENTADAS

FICHEIRO: server/routes/crmLeads.ts

Query params suportados (todos opcionais):
  1. q: string → pesquisa livre em (titulo, descricao, marca)
  2. estado: string → filtrar por estado (enum)
  3. entidadeId: UUID → filtrar por entidade específica (JÁ EXISTIA)
  4. contactoId: UUID → filtrar por contacto (JÁ EXISTIA)
  5. visitaId: UUID → filtrar por visita (JÁ EXISTIA)
  6. hasOdoo: "true"|"false" → filtrar se tem/não tem odooLeadId
  7. orderBy: "createdAt"|"titulo"|"entidade"|"valorPrevisto"
  8. orderDir: "asc"|"desc" (default: "desc" para createdAt, "asc" para titulo)

Implementação:

1) Query params com defaults (linhas 29-37):
   - q: undefined (sem pesquisa por default)
   - estado: undefined
   - entidadeId/contactoId/visitaId: undefined
   - hasOdoo: undefined
   - orderBy: "createdAt" (default)
   - orderDir: "desc" (default)

2) WHERE clause dinâmico (linhas 39-75):
   - Base: eq(leads.empresaId, empresaId)
   - q: OR(ilike(titulo), ilike(descricao), ilike(marca))
   - estado: eq(leads.estado, estado)
   - entidadeId: eq(leads.entidadeId, entidadeId)
   - contactoId: eq(leads.contactoId, contactoId)
   - visitaId: eq(leads.visitaId, visitaId)
   - hasOdoo === "true": isNotNull(leads.odooLeadId)
   - hasOdoo === "false": isNull(leads.odooLeadId)

3) ORDER BY dinâmico (linhas 77-95):
   - "titulo": order by titulo (asc/desc)
   - "valorPrevisto": order by valorPrevisto (asc/desc)
   - "entidade": client-side sort por entidade.nome (fallback: createdAt)
   - "createdAt": order by createdAt (default, asc/desc)

4) Paginação (linha 100):
   - LIMIT 100 por default
   - Pode ser expandido depois se necessário

5) Relations (linhas 101-109):
   - marcasAssociadas: para mapear para array de marcas
   - entidade: para sorting por nome
   - contacto: para contexto

6) Client-side entidade sorting (linhas 122-131):
   - Se orderBy === "entidade", faz sort em JS
   - Motivo: Drizzle query API não permite join com order by simples

FLUXOS DE USO (EXEMPLOS)
================================================================================

1) Listar leads com titulo contendo "Acme" (case-insensitive)
   GET /api/crm/leads?q=acme
   WHERE: empresaId = X AND (titulo ILIKE "%acme%" OR ...)

2) Listar leads em estado "fechado", ordenados por valor (asc)
   GET /api/crm/leads?estado=fechado&orderBy=valorPrevisto&orderDir=asc
   WHERE: empresaId = X AND estado = "fechado"
   ORDER BY: valorPrevisto ASC

3) Listar leads SEM sincronização Odoo, ordenados por nome da entidade
   GET /api/crm/leads?hasOdoo=false&orderBy=entidade&orderDir=asc
   WHERE: empresaId = X AND odooLeadId IS NULL
   ORDER BY: entidade.nome ASC (client-side)

4) Listar leads de entidade específica, pesquisa "contrato"
   GET /api/crm/leads?entidadeId=uuid&q=contrato
   WHERE: empresaId = X AND entidadeId = uuid AND titulo ILIKE "%contrato%"

5) Kombinado: estado + pesquisa + ordenação
   GET /api/crm/leads?estado=novo&q=oportunidade&orderBy=createdAt&orderDir=desc
   WHERE: empresaId = X AND estado = "novo" AND (titulo/descricao/marca ILIKE "%oportunidade%")
   ORDER BY: createdAt DESC
