2.1 FICHEIRO: shared/schema.ts
---

A) Nova Tabela - leads_marcas (linhas 758-763)

export const leadsMarcas = pgTable("leads_marcas", {
  id: varchar("id").primaryKey().default(sql`gen_random_uuid()`),
  leadId: varchar("lead_id").notNull().references(() => leads.id, { onDelete: 'cascade' }),
  marcaId: varchar("marca_id").notNull().references(() => marcas.id, { onDelete: 'restrict' }),
  createdAt: timestamp("created_at").defaultNow().notNull(),
});

Campos:
  - id: UUID, primary key (auto-gerado)
  - leadId: FK → leads.id, ON DELETE CASCADE
    -> Se lead for eliminado, todas as marcas associadas sao removidas
  - marcaId: FK → marcas.id, ON DELETE RESTRICT
    -> Nao permite eliminar uma marca se tiver leads associados
  - createdAt: timestamp, auto-preenchido com now()

B) Relacoes Drizzle (linhas 766-775)

export const leadsMarcasRelations = relations(leadsMarcas, ({ one }) => ({
  lead: one(leads, {
    fields: [leadsMarcas.leadId],
    references: [leads.id],
  }),
  marca: one(marcas, {
    fields: [leadsMarcas.marcaId],
    references: [marcas.id],
  }),
}));

Permite: leadsMarcas -> lead, leadsMarcas -> marca

C) Insert Schema e Tipos (linhas 777-783)

export const insertLeadsMarcasSchema = createInsertSchema(leadsMarcas).omit({
  id: true,
  createdAt: true,
});

export type InsertLeadsMarcas = z.infer<typeof insertLeadsMarcasSchema>;
export type LeadsMarcas = typeof leadsMarcas.$inferSelect;

Tipos exportados:
  - InsertLeadsMarcas: Para criar novos registos (sem id, createdAt)
  - LeadsMarcas: Tipo full do registo em BD

D) Relacao em leadsRelations (linha 705)

export const leadsRelations = relations(leads, ({ one, many }) => ({
  ...
  contactosAssociados: many(leadsContactos),
  marcasAssociadas: many(leadsMarcas),  <- NOVO
}));

Permite: lead -> leadsMarcas[]

3. ESTRUTURA ATUAL EM BD
================================================================================

Tabelas Relacionadas:

  marcas
  ├─ id: PK
  ├─ empresaId: FK → empresas
  ├─ nome, codigo, descricao, logoUrl, ativa
  └─ createdAt, updatedAt

  leads
  ├─ id: PK
  ├─ empresaId: FK → empresas
  ├─ entidadeId: FK → entidades
  ├─ contactoId: FK → contactos (primary contact)
  ├─ visitaId: FK → visitas (optional)
  ├─ titulo, descricao, marca (texto)
  ├─ estado, valorPrevisto, moeda
  ├─ responsavelUserId
  ├─ odooLeadId (sync com Odoo)
  ├─ createdAt, updatedAt
  └─ Relations:
      ├─ empresa
      ├─ entidade
      ├─ contacto
      ├─ visita
      ├─ contactosAssociados: many(leadsContactos)
      └─ marcasAssociadas: many(leadsMarcas) <- NOVO

  leads_contactos (junction table - ja existente)
  ├─ id: PK
  ├─ leadId: FK → leads
  ├─ contactoId: FK → contactos
  ├─ role (opcional)
  └─ createdAt

  leads_marcas (junction table - NOVO)
  ├─ id: PK
  ├─ leadId: FK → leads (CASCADE)
  ├─ marcaId: FK → marcas (RESTRICT)
  └─ createdAt

Fluxo de Dados (futuro):
  1. Lead criado com contactoId (primary contact)
  2. Lead pode ter N contactos em leads_contactos
  3. Lead pode ter N marcas em leads_marcas <- NOVO
  4. Campos marca em leads continua como texto resumido (compatibilidade)
