PROBLEMA DESCRITO
================================================================================

Cenario do Bug:
  1. User em /visitas/:visitaId (SEM /admin)
  2. Clica "Novo lead desta visita"
  3. Cria lead e clica "Guardar"
  4. Toast: "Lead criado"
  5. RESULTADO: Navega para /admin/visitas/:visitaId → 404 ❌
  
Root Cause:
  - App codificava returnTo com `/admin/visitas/` em VisitaDetail.tsx
  - AdminLeadDetailPage.tsx usava `/admin/visitas/` para navegar
  - Mas a rota correcta para user flows eh `/visitas/` (sem /admin)
  - Resultado: 404 porque rota nao existe

================================================================================
SOLUCAO IMPLEMENTADA
================================================================================

Ficheiro 1: client/src/pages/VisitaDetail.tsx (linha 325)

ANTES:
  const returnTo = `/admin/visitas/${visita.id}`;

DEPOIS:
  const returnTo = `/visitas/${visita.id}`;

EFEITO: returnTo agora contem a rota correcta ✅
