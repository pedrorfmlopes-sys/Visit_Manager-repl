PROBLEMA RESOLVIDO
================================================================================

ERRO: "null value in column "contacto_id" of relation "leads_contactos" violates not-null constraint"

CAUSA: Quando criava lead SÓ com entidadeId (sem contactoId):
  - Backend aceitava (FASE-LEADS-CLEAN-01: contactoId nullable)
  - Mas inseria INCONDICIONALMENTE em leads_contactos
  - Tentava inserir: { leadId: "...", contactoId: null }
  - Violava NOT NULL constraint da tabela leads_contactos

SOLUÇÃO: Tornar o insert em leads_contactos condicional
  - Só inserir quando contactoId é válido (não null, não undefined)
  - Não alterar schema de leads_contactos (continua NOT NULL)
