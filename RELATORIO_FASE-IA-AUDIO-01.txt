1. O QUE FOI FEITO
================================================================================

✅ Criado hook reutilizável: client/src/hooks/useAudioTranscription.ts

Funcionalidades:
- startRecording(): Inicia gravação com MediaRecorder + getUserMedia
- stopRecording(): Para gravação
- transcribe(blob?): Transcreve áudio via POST a um endpoint configurável
- clearAudio(): Limpa estado após uso
- recordingTime: Contador de segundos a gravar
- isRecording, isTranscribing, hasAudio: Estados para UI
- supportsRecording: Deteta se browser suporta gravação

Configurável via options:
- transcriptionEndpoint: URL do endpoint (default: /api/visitas/ai/transcribe)
- onTranscriptionComplete: Callback ao transcrever com sucesso
- onError: Callback em caso de erro

Padrão de uso:
```typescript
const audio = useAudioTranscription({
  transcriptionEndpoint: '/api/crm/leads/ai/transcribe',
  onTranscriptionComplete: (text) => {
    // fazer algo com o texto transcrito
  }
});

// UI
<button onClick={audio.isRecording ? audio.stopRecording : audio.startRecording}>
  {audio.isRecording ? 'Parar' : 'Gravar'}
</button>

// Transcrever
const text = await audio.transcribe();
```

3. COMO O HOOK FUNCIONA (Internamente)
================================================================================

Fluxo de gravação:
1. startRecording() → navigator.mediaDevices.getUserMedia({ audio: true })
2. Cria MediaRecorder instance
3. setupListeners:
   - ondataavailable: acumula chunks de áudio em array
   - onstop: junta chunks num Blob (audio/webm) e salva em audioBlob ref
   - onerror: captura erros e informa user
4. mediaRecorder.start()
5. setIsRecording(true)
6. inicia timer de contagem (recordingTime)

Fluxo de transcrição:
1. transcribe(blob?) → recebe blob ou usa audioBlob guardado
2. Validação: se não existe áudio → erro
3. FormData com arquivo
4. POST para endpoint (configurável)
5. Response: { success: true, text: "..." } ou { success: false, message: "..." }
6. Se sucesso: callback onTranscriptionComplete + toast + return text
7. Se erro: callback onError + toast + throw error

Cleanup:
- useEffect cleanup: para MediaRecorder se ainda a gravar
- Stop media stream tracks
- Clear intervals

7. COMO USAR O HOOK (Exemplo Prático)
================================================================================

No componente:

```typescript
import { useAudioTranscription } from '@/hooks/useAudioTranscription';

export function MyComponent() {
  const [description, setDescription] = useState('');
  const { toast } = useToast();

  const audio = useAudioTranscription({
    transcriptionEndpoint: '/api/crm/leads/ai/transcribe',
    onTranscriptionComplete: (text) => {
      setDescription(prev => prev + '\n\n[Áudio transcrito]\n' + text);
    },
    onError: (error) => {
      console.error('Audio error:', error);
    }
  });

  const handleTranscribe = async () => {
    try {
      await audio.transcribe();
    } catch (error) {
      // Error already handled by hook
    }
  };

  return (
    <div>
      <button onClick={audio.isRecording ? audio.stopRecording : audio.startRecording}>
        {audio.isRecording ? `Gravando... ${audio.recordingTime}s` : 'Gravar'}
      </button>
      
      {audio.hasAudio && !audio.isRecording && (
        <button 
          onClick={handleTranscribe}
          disabled={audio.isTranscribing}
        >
          {audio.isTranscribing ? 'A transcrever...' : 'Transcrever áudio'}
        </button>
      )}

      <textarea value={description} onChange={(e) => setDescription(e.target.value)} />
    </div>
  );
}
```
