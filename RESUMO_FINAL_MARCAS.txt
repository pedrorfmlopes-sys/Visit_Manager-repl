1. DIAGNOSTICO DO PROBLEMA
================================================================================

Sintoma Inicial:
  "Crio uma marca, não vejo erro, mas marca não aparece na lista"

O que foi investigado:
  1. ✓ Backend routes: OK (logs adicionados, código correto)
  2. ✓ Storage marcas: OK (logs adicionados, funções corretas)
  3. ✓ Database: ✓✓✓ OK (teste automático confirmou 100% funcional)
  4. ✗ Frontend AdminMarcas.tsx: ❌ ENCONTRADO O ERRO

Problema Real Identificado:
  → HTML Form Aninhadas Causando React Hook Form Errors
  
  AdminMarcas.tsx usava <form> tags
  MAS AdminMarcas está renderizado dentro de AdminEmpresa que tem <Form> shadcn
  = Resultado: <form> aninhada dentro de outra <form>
  = HTML Error: "validateDOMNesting(...): <form> cannot appear as descendant of <form>"
  = React Hook Form quebrado: "Invalid hook call"
  = Mutations silenciosas: chamadas mas sem callback correto
  = invalidateQueries falhava: por causa do hook error

================================================================================
2. SOLUCAO IMPLEMENTADA
================================================================================

Ficheiro Corrigido: client/src/pages/AdminMarcas.tsx

Mudança 1: Formulário de CRIAR marca

  Para: <div className="space-y-4">
  
  Button mudado de:  <Button type="submit" ...>

  Resultado: Sem <form> aninhada, React Hook Form funciona corretamente

Mudança 2: Formulário de EDITAR marca

  Button mudado de:  <Button type="submit" ...>
