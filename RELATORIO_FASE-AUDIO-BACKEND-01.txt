1. PROBLEMA IDENTIFICADO
================================================================================

SINTOMA:
- Frontend: "Erro na transcrição - HTTP 500: {"success":false,"message":"Falha ao transcrever áudio. Por favor, tenta novamente."}"
- Endpoint: POST /api/crm/leads/ai/transcribe
- Quando: User clica "Transcrever áudio" em Visita ou Lead

RAIZ DO PROBLEMA (Linhas 621-626 em server/routes/crmLeads.ts):
```typescript
if (!result.text || result.text.includes("indisponível")) {
  console.warn("[CRM Leads AI] Transcription returned warning/placeholder text", { text: result.text });
  return res.status(500).json({    // ← BUG: Retorna 500!
    success: false, 
    message: "IA não está configurada. Contacta o administrador." 
  });
}
```

FLUXO DO BUG:
1. User grava áudio ✓
2. Frontend envia POST /api/crm/leads/ai/transcribe ✓
3. Handler chama transcribeAudio() em server/openai.ts ✓
4. transcribeAudio() sem OPENAI_API_KEY:
   - Retorna: { text: "[Transcrição automática indisponível - API key não configurada]" }
   - Está CORRETO - função não lançou erro
5. Handler verifica: result.text.includes("indisponível") === true
6. Retorna res.status(500) ← PROBLEMA!
7. Status 500 = "Internal Server Error"
8. Frontend mostra erro como se fosse bug servidor ✗

POR QUE É BUG:
- Status 500 = Internal Server Error = algo deu muito errado no servidor
- Realidade: API key está faltando (situação CONHECIDA)
- Deveria ser: Status 503 = Service Unavailable OU 200 com success:false

10. NOTAS TÉCNICAS
================================================================================

POR QUE STATUS 503?
- 500 = Internal Server Error (algo deu muito errado)
- 503 = Service Unavailable (serviço está down/indisponível)
- API key faltando = Serviço de IA indisponível
- Semanticamente correto: 503

POR QUE RETORNAR PLACEHOLDER E NÃO LANÇAR ERRO?
- Graceful Degradation: Sistema continua funcionando
- Utilizador pode gravar e enviar áudio mesmo sem IA
- Mensagem clara: "IA não está configurada"
- Evita erro 500 inesperado

TRATAMENTO DE FICHEIRO:
- Multer: memory storage, max 25MB
- Validações: ficheiro deve ter conteúdo (>0 bytes)
- Temp file: Criado em /tmp, automaticamente limpo
