6. ARQUITETURA TECNICA
================================================================================

DATA FLOW:
  Visita (backend)
    ↓
    ├─ entidade { id, nome, ... }
    ├─ contacto { id, nome, ... } (FK na Visita)
    └─ contactosPresentes [] (pivot VisitasContactos)
         ↓
    AdminLeadDetailPage
      ↓
      ├─ visitaData (useQuery)
      ├─ contactosDisponiveis array
      ├─ lead mock (entidadeNome, contactoNome preenchidos)
         ↓
    LeadDetailForm
      ↓
      ├─ form.contactoId (state)
      ├─ <Select> com contactosDisponiveis
      ├─ handleSave lê form.contactoId
         ↓
    POST /api/crm/leads
      ↓
      body: { ..., contactoId: form.contactoId }
      ↓
    Backend valida FK
    ↓
    Lead criado com contactoId correto

VALIDACAO:
  Cliente:
    - if (!form.contactoId) → toast error
    - if (!entidadeId) → toast error
  
  Servidor:
    - if (!body.contactoId) → 400 Bad Request
    - if (!body.entidadeId) → 400 Bad Request
    - FK constraint check
