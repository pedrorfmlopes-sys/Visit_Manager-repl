3. FLUXO DE DADOS
================================================================================

EXEMPLO 1: POST /api/crm/leads com marcasIds

Request Body:
  {
    "entidadeId": "ent-1",
    "contactoId": "con-1",
    "titulo": "Oportunidade A",
    "marcasIds": ["marca-1", "marca-2"]  // NOVO
  }

Backend Processamento:
  1. Validar schema (marcasIds: string[])
  2. Buscar marcas: SELECT * FROM marcas WHERE id IN ('marca-1', 'marca-2')
     Resultado: [{ id: 'marca-1', nome: 'Ritmonio' }, { id: 'marca-2', nome: 'Bette' }]
  3. finalMarca = "Ritmonio, Bette"
  4. INSERT lead { marca: "Ritmonio, Bette", ... }
  5. INSERT leads_marcas { leadId: 'lead-1', marcaId: 'marca-1' }
  6. INSERT leads_marcas { leadId: 'lead-1', marcaId: 'marca-2' }

Response:
  {
    "success": true,
    "lead": {
      "id": "lead-1",
      "marca": "Ritmonio, Bette",
      ...
    }
  }

Logs:
  [CRM Leads] POST created lead { id: 'lead-1', marcasCount: 2 }

EXEMPLO 2: PATCH /api/crm/leads/:id com novo marcasIds

Request Body:
  PATCH /api/crm/leads/lead-1
  {
    "marcasIds": ["marca-2", "marca-3"]  // Mudou de 1,2 para 2,3
  }

Backend Processamento:
  1. Validar que marcasIds e definido
  2. Buscar marcas: SELECT * FROM marcas WHERE id IN ('marca-2', 'marca-3')
     Resultado: [{ nome: 'Bette' }, { nome: 'Kora' }]
  3. updateData.marca = "Bette, Kora"
  4. UPDATE leads SET marca = "Bette, Kora" WHERE id = 'lead-1'
  5. DELETE FROM leads_marcas WHERE lead_id = 'lead-1'
  6. INSERT leads_marcas { leadId: 'lead-1', marcaId: 'marca-2' }
  7. INSERT leads_marcas { leadId: 'lead-1', marcaId: 'marca-3' }
  8. REFETCH lead
  9. RETURN lead atualizado

Logs:
  [CRM Leads] PATCH updated lead { id: 'lead-1', marcasCount: 2 }

4. CASOS DE USO
================================================================================

CASO 1: Criar lead com multiplas marcas
  POST /api/crm/leads { marcasIds: ['m1', 'm2', 'm3'] }
  -> marca = "Marca1, Marca2, Marca3"
  -> 3 records em leads_marcas
  -> GET /api/crm/leads/:id mostra marcas: [{ id, nome }, ...]

CASO 2: Editar lead - mudar marcas
  PATCH /api/crm/leads/:id { marcasIds: ['m4'] }
  -> marca = "Marca4"
  -> Apagar antigos em leads_marcas
  -> Inserir novo

CASO 3: Cliente antigo sem marcasIds
  POST /api/crm/leads { marca: "Ritmonio" }
  -> marca = "Ritmonio"
  -> Sem leads_marcas
  -> Funciona igual ao anterior

CASO 4: Editar outros campos E marcasIds
  PATCH /api/crm/leads/:id { titulo: "...", marcasIds: ['m1'] }
  -> UPDATE leads (titulo + marca)
  -> DELETE/INSERT em leads_marcas
  -> REFETCH lead
  -> Return atualizado
