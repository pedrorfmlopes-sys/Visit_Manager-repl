================================================================================
PROBLEMA IDENTIFICADO
================================================================================

Error em browser console:
"A <Select.Item /> must have a value prop that is not an empty string. 
This is because the Select value can be set to an empty string to clear the 
selection and show the placeholder."

Causa:
- AdminLeadsPage.tsx tinha 3 SelectItems com value="" (string vazia)
- Estado: <SelectItem value="">Todos</SelectItem>
- Entidade: <SelectItem value="">Todas</SelectItem>
- Contacto: <SelectItem value="">Todos</SelectItem>

Radix UI Select constraint:
- Não permite value="" porque "" é usado para "clear selection"
- Conflito de semântica: "" tem significado especial no Select

================================================================================
SOLUCAO IMPLEMENTADA
================================================================================

Padrão: "all" para representar "mostrar tudo"

1) Substituir value="" por value="all" em SelectItems:
   ✅ Estado: value="all" → "Todos"
   ✅ Entidade: value="all" → "Todas"
   ✅ Contacto: value="all" → "Todos"

2) Atualizar handlers (onValueChange):
   ✅ Estado:
      value={estado || "all"} 
      onValueChange={(value) => updateParams({ estado: value === "all" ? "" : value })}
   
   ✅ Entidade:
      value={entidadeId || "all"}
      onValueChange={(value) => updateParams({ entidadeId: value === "all" ? "" : value })}
   
   ✅ Contacto:
      value={contactoId || "all"}
      onValueChange={(value) => updateParams({ contactoId: value === "all" ? "" : value })}

3) Lógica:
   - User seleciona "Todos" → Select value = "all"
   - Handler detecta "all" → converte para "" antes de updateParams
   - updateParams("") → remove query param da URL (ternary em updateParams)
   - Estado interno: "" (sem filtro)
   - Select renderiza: "all" (placeholder "Todos os estados")
