3. PADROES IMPLEMENTADOS
================================================================================

A. BADGES EM LISTAS (até 2 + "+N"):

Lógica:
  {lead.marcas && lead.marcas.length > 0 ? (
    <div className="flex flex-wrap gap-1">
      {lead.marcas.slice(0, 2).map((marca) => (
        <Badge key={marca.id} variant="secondary" className="text-xs" 
               data-testid={`badge-lead-marca-${marca.id}`}>
          {marca.nome}
        </Badge>
      ))}
      {lead.marcas.length > 2 && (
        <Badge variant="outline" className="text-xs" 
               data-testid={`badge-lead-marcas-more-${lead.id}`}>
          +{lead.marcas.length - 2}
        </Badge>
      )}
    </div>
  ) : (
    "—"
  )}

Características:
  * flex flex-wrap gap-1: Compacto, mobile-friendly
  * variant="secondary": Cor discreta
  * className="text-xs": Texto pequeno
  * .slice(0, 2): Apenas primeiras 2 marcas
  * +N indicator: Se mais de 2 marcas
  * data-testid: Identificação para testes


B. MARCAS EM DETALHE (TODAS):

Lógica (AdminLeadDetailPage.tsx):
  {lead.marcas && lead.marcas.length > 0 && (
    <div className="space-y-1.5 border-t pt-3">
      <div className="text-xs text-muted-foreground font-medium">
        Marcas associadas:
      </div>
      <div className="flex flex-wrap gap-2">
        {lead.marcas.map((marca) => (
          <Badge key={marca.id} variant="secondary" 
                 data-testid={`badge-lead-detalhe-marca-${marca.id}`}>
            {marca.nome}
          </Badge>
        ))}
      </div>
    </div>
  )}

Características:
  * space-y-1.5: Espaçamento vertical
  * border-t pt-3: Separador visual
  * .map((marca)): TODAS as marcas, não apenas 2
  * variant="secondary": Cor consistente com listas
  * flex wrap gap-2: Maior espaço que em listas
  * Condicional: Só mostra se hay marcas
